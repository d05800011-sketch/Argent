# Argent — своё приложение для скачивания видео (бесплатно)

Сайт-приложение (PWA) для iPhone: регистрация и вход, скачивание видео по ссылке, хранение в библиотеке, сохранение в «Файлы». Стеклянный интерфейс на хромированном фоне.

Всё работает на бесплатных тарифах: **GitHub Pages** (сайт), **Supabase** (вход, база, хранилище), **Cloudflare Workers** (загрузка видео по ссылке).

## Что нужно знать сразу

- Скачиваются **прямые ссылки на файл** (`.mp4`, `.mov`, `.webm`).
- Ссылки на YouTube, TikTok, Instagram и подобные платформы напрямую не работают: они отдают видео не файлом. Для них нужен отдельный сервис-экстрактор (например, свой cobalt), адрес вписывается в ⚙︎ Настройки. Публичные экстракторы часто требуют ключ или блокируют запросы, поэтому гарантии нет. Платформы также запрещают скачивание в своих правилах: качайте только то, на что у вас есть права.
- Лимит бесплатного Supabase: **50 МБ на файл** и **1 ГБ** на всё хранилище.
- Сервис Supabase на бесплатном тарифе «засыпает» после недели без активности, при следующем открытии его нужно разбудить в панели управления.

## Установка (около 15 минут)

### 1. Supabase
1. Зайдите на supabase.com, создайте проект (Free).
2. SQL Editor → New query → вставьте содержимое `supabase.sql` → Run.
3. Authentication → Providers → Email: для простоты выключите «Confirm email» (иначе после регистрации нужно подтверждать почту).
4. Project Settings → API: скопируйте **Project URL** и ключ **anon public**.

### 2. Cloudflare Worker
1. Зайдите на dash.cloudflare.com → Workers & Pages → Create → Worker → Deploy.
2. Edit code → вставьте содержимое `worker.js` → Deploy.
3. Settings → Variables and Secrets, добавьте:
   - `SUPABASE_URL` — Project URL
   - `SUPABASE_ANON_KEY` — ключ anon public
   - `ALLOWED_ORIGIN` — адрес вашего сайта, например `https://ВАШ-ЛОГИН.github.io`
4. Скопируйте адрес воркера вида `https://argent-proxy.xxx.workers.dev`.

### 3. Настройка приложения
Откройте `config.js` и впишите `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `WORKER_URL`.

**Обязательно заполните блок `OPERATOR`** (ФИО или название владельца, почта для обращений, реквизиты, регион Supabase, автор фонового изображения). Пока поля пустые, на страницах документов они подсвечены жёлтым «ЗАПОЛНИТЕ». Публиковать сайт с жёлтыми пометками нельзя.

### 4. GitHub Pages
1. Создайте репозиторий, загрузите в него все файлы из этой папки (кроме `README.md` и `supabase.sql`, если не хотите их публиковать).
2. Settings → Pages → Branch: `main` / root → Save.
3. Через минуту сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

### 5. Установка на iPhone
Откройте адрес в **Safari** → «Поделиться» → «На экран “Домой”». Приложение появится на главном экране и откроется без адресной строки.

## Как пользоваться
- **Скачать:** вставьте ссылку на видеофайл, нажмите «Скачать». Видео попадёт в «Библиотеку».
- **Библиотека:** нажмите на превью, чтобы посмотреть. «В “Файлы”»: первое нажатие готовит файл, второе открывает меню iPhone, там выберите «Сохранить в “Файлы”» (или «Сохранить видео» для Фото).
- **Удалить:** убирает видео из хранилища.

## Файлы
| Файл | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js` | интерфейс и логика |
| `config.js` | ваши адреса и ключ |
| `worker.js` | прокси для загрузки (Cloudflare) |
| `supabase.sql` | таблица и правила доступа |
| `manifest.json`, `sw.js`, `icon*.png/svg`, `bg.jpg` | установка на экран «Домой», фон |
| `privacy.html`, `consent.html`, `terms.html`, `cookies.html`, `license.html`, `legal.js`, `LICENSE` | политика конфиденциальности, согласие на данные, условия, cookie, лицензия |

Ключ `anon public` можно держать в сайте: данные защищены правилами доступа из `supabase.sql`, каждый видит только свои файлы. Ключ `service_role` нигде не используйте.

## Документы и законность (прочитайте до публикации)

Документы написаны как заготовки, а не как юридическое заключение. Перед открытием сайта для других людей покажите их юристу.

1. **Заполните `OPERATOR` в `config.js`** (см. выше) и замените имя в файле `LICENSE`.
2. **Хранение данных россиян.** Закон о персональных данных (152-ФЗ) требует записывать и хранить персональные данные граждан России в базах на территории России. Supabase, Cloudflare и GitHub находятся за рубежом, поэтому для сайта, открытого россиянам, это главный юридический риск бесплатной схемы. Варианты: ограничить сайт кругом знакомых, перенести базу и хранилище на российский хостинг или проконсультироваться с юристом.
3. **Уведомление Роскомнадзора.** По источникам, оператор персональных данных (включая ИП и самозанятых) подаёт уведомление в Роскомнадзор до начала обработки. Проверьте у юриста, относится ли это к вам.
4. **Согласие** при регистрации идёт двумя отдельными галочками (условия и согласие на данные). Не объединяйте их.
5. **Cookie и аналитика.** Сейчас используется только необходимое хранение (вход, настройки), аналитики нет, поэтому запрос согласия не нужен. Если подключите аналитику или рекламу, сначала добавьте баннер с кнопками «Принять» и «Отказаться» и обновите `cookies.html`.
6. **Удаление аккаунта** работает после того, как вы выполните обновлённый `supabase.sql` (в нём добавлена функция `delete_my_account`).
7. **Изображения.** Убедитесь, что у вас есть права на фон `bg.jpg`, и впишите автора в `OPERATOR.imageCredit`.
8. **Название.** «Argent» не проверялось на занятость как товарный знак.
